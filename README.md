# a-to-z-estafette-proof

Smalle BUILD-455 v0.1 productoutput: een kleine lokale checklist-webapp in de browser.

## Openen

1. Open lokaal het bestand `index.html` in een browser (bijv. via dubbelklik of drag-and-drop in een browservenster).

## Gebruiken

1. Vink taken aan in de checklist.
2. Bekijk de statusmelding onder de lijst.
3. Klik op **Reset / schone lei** om alles te wissen.

## Kort testen

- Checklist is zichtbaar.
- Taken kunnen afgevinkt worden.
- Status verandert direct en toont **klaar** als alles afgevinkt is.
- Reset zet alle vinkjes en status terug.
